# Workshops

Each workshop from a DevDogs meeting, written up so you can follow it on your own: if you missed the night, fell behind during the live demo, or want to go through it again. Workshops run for both stacks, so most have a Next.js track and a Flutter track side by side; pick the one your team builds with.

New here? Install what you need from the [Prerequisites](./getting-started/prerequisites), then read [Git & GitHub](./git-and-github): every workshop builds on both.

A track is a sequence of steps. The sidebar ticks off each step you finish, and the bottom of every step links to the next one. Your progress is saved in this browser.

The code for every workshop lives in two public repositories, one per stack: [Web-Workshops](https://github.com/DevDogsUGA/Web-Workshops) for Next.js and [Mobile-Workshops](https://github.com/DevDogsUGA/Mobile-Workshops) for Flutter. Each workshop has its own branch, and each step links to its files as they stood at that point.
