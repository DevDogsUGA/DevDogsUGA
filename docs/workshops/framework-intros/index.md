# Workshop: Framework Intros

On Sep 21, 2026, after a shared hour of installing tools, the room split in two. Kyle Quach led a Next.js room, and Nandan Praveen led a Flutter room with GDGC. Each track here is that room's workshop as a course you can follow at your own pace, and each one goes as far as the code in the workshop repo. In the room, Next.js got through components and Flutter through widgets.

Pick the track for the stack you want to learn:

- **[Intro to Next.js](./nextjs/setup)** builds a small personal site: a home page, an About section, a Projects page, a navigation bar, and a guestbook. Adapted by Sloan Finger from Kyle Quach's Next.js workshop, Sep 21, 2026.
- **[Intro to Flutter](./flutter/setup)** builds a two-tab app: a home screen and a guestbook. Adapted by Sloan Finger from Nandan Praveen's Flutter workshop with GDGC, Sep 21, 2026.

## Before You Start

The shared hour of installs isn't repeated here: the [Prerequisites](../getting-started/prerequisites) cover it. You need the **For everyone** section, then [For the Next.js track](../getting-started/prerequisites#for-the-nextjs-track) or [For the Flutter track](../getting-started/prerequisites#for-the-flutter-track).

## Where It Leads

Both tracks end with a guestbook that forgets its entries on refresh. The [Supabase workshop](../supabase/concepts) starts from exactly that code and gives the guestbook a real database, sign-in, and row-level security.
