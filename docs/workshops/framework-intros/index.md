# Workshop: Framework Intros

A first app in Next.js or Flutter. Pick the track for the stack you want to learn:

- **[Intro to Next.js](./nextjs/setup.md)** builds a small personal site: a home page, an About section, a Projects page, a navigation bar, and a guestbook.
- **[Intro to Flutter](./flutter/setup.md)** builds a two-tab app: a home screen and a guestbook.

> [!IMPORTANT]
> Install the tools first: the **For everyone** section of the [Prerequisites](../../_shared/getting-started/prerequisites.md), then [For the Next.js track](../../_shared/getting-started/prerequisites.md#for-the-nextjs-track) or [For the Flutter track](../../_shared/getting-started/prerequisites.md#for-the-flutter-track).

## Where It Leads

Both tracks end with a guestbook that forgets its entries on refresh. The [Supabase workshop](../supabase/concepts.md) starts from exactly that code and gives the guestbook a real database, sign-in, and row-level security.
