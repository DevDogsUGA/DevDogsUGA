# Study Group Finder

Study Group Finder is DevDogs' Flutter mobile app for finding and forming study groups at UGA.

> [!NOTE]
> Documentation for this project is still being written. Add markdown files under
> `docs/study-group-finder/` and they will appear in the sidebar automatically.

## Where the code lives

The app lives at `apps/study-group-finder`. Unlike the other apps it is Flutter rather
than Next.js, so it is validated by its own CI job and is excluded from the repo-wide
`turbo run` tasks.
